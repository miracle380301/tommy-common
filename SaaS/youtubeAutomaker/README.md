# YouTube Automaker

자동으로 YouTube 동영상을 생성하는 프로그램입니다.

## 🚀 빠른 시작

### 필요 프로그램
- **Node.js 16+** (다운로드: https://nodejs.org/)
- **Python 3.8+** (다운로드: https://python.org/)

### 실행 방법
1. `실행.bat` 파일을 더블클릭
2. 브라우저에서 `http://localhost:3000` 자동 실행
3. 영상 제작 시작!

### 수동 설치 (선택사항)
```bash
npm install
npm run install-all
npm run dev
```

## 🎯 주요 기능

- **스크립트 편집**: 비디오 텍스트 작성
- **음성 생성**: 고품질 TTS (한국어/영어)
- **이미지 관리**: 키워드 검색 또는 직접 업로드
- **음악 선택**: 다양한 장르의 배경음악
- **템플릿 시스템**: 미리 만들어진 비디오 템플릿

## 🔧 문제 해결

### 실행이 안 될 때
1. Node.js와 Python이 설치되어 있는지 확인
2. `실행.bat` 파일을 관리자 권한으로 실행
3. 바이러스 백신에서 폴더를 예외 처리

### 포트 충돌 시
- 포트 3000, 8000을 사용하는 다른 프로그램 종료
- 재실행
