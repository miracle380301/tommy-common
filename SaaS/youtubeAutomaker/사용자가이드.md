# YouTube Automaker 사용자 가이드

## 📥 설치 및 실행

### 1단계: 필수 프로그램 설치
1. **Node.js 설치** (https://nodejs.org/)
   - LTS 버전 다운로드 및 설치
   - 설치 후 컴퓨터 재시작

2. **Python 설치** (https://python.org/)
   - Python 3.8 이상 다운로드 및 설치
   - 🔥 **중요**: 설치 시 "Add Python to PATH" 체크!

### 2단계: 프로그램 실행
1. `실행.bat` 파일을 **더블클릭**
2. 첫 실행시 자동으로 필요한 파일들이 설치됩니다 (시간이 걸릴 수 있음)
3. 브라우저에서 `http://localhost:3000`이 자동으로 열립니다

## ⚙️ 실행 전 필수 설정

### Google TTS 설정 (한국어 음성 사용시)
1. **Google Cloud Console** 접속 (https://console.cloud.google.com/)
2. **새 프로젝트 생성** 또는 기존 프로젝트 선택
3. **Text-to-Speech API 활성화**
4. **서비스 계정 생성**:
   - IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기
   - 역할: Text-to-Speech 관리자
5. **키 다운로드**:
   - 생성된 서비스 계정 → 키 → 키 추가 → JSON
   - 다운로드된 JSON 파일을 `tts_service.json`으로 이름 변경
6. **파일 배치**:
   ```
   Backend/config/tts_service.json
   ```

### Unsplash API 설정 (이미지 검색 사용시)
1. **Unsplash Developers** 접속 (https://unsplash.com/developers)
2. **새 애플리케이션 등록**
3. **Access Key 복사**
4. **파일 생성**:
   ```
   Backend/config/unsplash_api_key.txt
   ```
   파일 내용: 복사한 Access Key

## 🎬 사용 방법

### 1. 스크립트 작성
- **Script** 탭에서 비디오에 사용할 텍스트 입력
- 문장별로 줄바꿈하면 자연스러운 음성 생성

### 2. 음성 선택
- **Voice** 탭에서 원하는 음성 선택
- 한국어: Google TTS (설정 필요)
- 영어: gTTS (설정 불필요)

### 3. 이미지 설정
- **Image** 탭에서 이미지 선택
- **키워드 검색**: Unsplash에서 자동 검색 (API 키 필요)
- **직접 업로드**: 로컬 이미지 파일 업로드

### 4. 음악 선택
- **Music** 탭에서 배경음악 선택
- 기본 제공 음악 또는 직접 업로드

### 5. 템플릿 선택
- **Template** 탭에서 비디오 템플릿 선택

### 6. 비디오 생성
- **Submit** 버튼 클릭
- 생성 진행 상황 확인
- 완료 시 다운로드 링크 제공

## 📂 출력 파일 위치

생성된 파일들은 다음 위치에 저장됩니다:

```
Backend/data/
├── img/                    # 다운로드된 이미지
│   └── 20250804/          # 날짜별 폴더
├── music/                 # 선택된 음악
│   └── 20250804/          # 날짜별 폴더
├── voice/                 # 생성된 음성
│   └── 20250804/          # 날짜별 폴더
├── scripts/               # 자막 파일 (.srt)
│   └── 20250804/          # 날짜별 폴더
└── video/                 # 🎯 최종 비디오 파일
    └── 20250804/          # 날짜별 폴더
        └── 20250804.mp4   # 완성된 비디오
```

### 📹 완성된 비디오 찾기
**`Backend/data/video/[날짜]/[날짜].mp4`**

예시: `Backend/data/video/20250804/20250804.mp4`

## 🔧 문제 해결

### 실행이 안 될 때
1. **Node.js 설치 확인**: 명령프롬프트에서 `node --version`
2. **Python 설치 확인**: 명령프롬프트에서 `python --version`
3. **관리자 권한으로 실행**: `실행.bat` 우클릭 → 관리자 권한으로 실행
4. **바이러스 백신 예외 처리**: 프로젝트 폴더를 바이러스 백신 예외 목록에 추가

### 포트 사용 중 오류
1. **다른 프로그램 종료**: 포트 3000, 8000을 사용하는 프로그램 종료
2. **작업 관리자**: Python, Node 프로세스 강제 종료
3. **재시작**: 컴퓨터 재시작 후 다시 실행

### 음성 생성 실패
1. **Google TTS 설정 확인**: `Backend/config/tts_service.json` 파일 존재 및 내용 확인
2. **인터넷 연결**: Google API 사용을 위한 인터넷 연결 필요
3. **API 한도**: Google Cloud Console에서 사용량 확인

### 이미지 검색 안 됨
1. **Unsplash API 키 확인**: `Backend/config/unsplash_api_key.txt` 파일 확인
2. **인터넷 연결**: API 사용을 위한 인터넷 연결 필요
